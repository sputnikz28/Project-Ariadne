# Kors de Elarion

**Home:** Elarion · **Arrived:** Era VII.2 · **Council weight:** 1.0

Four independent observers, each reading a different statistical lens
through Ariadne — overdue numbers, rarest numbers, transitions,
weekly echoes. Never read raw data directly. See [`lore.md`](lore.md)
for the full narrative history.
