# Lobisomens de Fenrir

**Home:** Floresta da Lua Cheia · **Arrived:** Era III — O Mundo Vivo · **Council weight:** 0.80 (only active near the full moon)

Monte Carlo simulation across thousands of attempts, kept only when
the moon allows the pack to act. One of two forces (with the Clérigos)
able to purify a corrupted Council key. See [`lore.md`](lore.md) for
the full narrative history.

| File | Contents |
|---|---|
| `lore.md` | History, homeland, philosophy, hierarchy, Council and inter-race relationships |
| `lineages.json` | The single pack lineage (no separate clans) |
| `characters.json` | 1 archetypal character (Fenrir, the pack's collective spirit) |
| `artifacts.json` | 2 artifacts |

**Faction plugin:** [`factions/werewolves/`](../../factions/werewolves)
— `algorithm.py` implements `werewolves()`, the Council-voting
generator.
